# wakamore

音楽に合わせて遊べる高速モグラ叩きゲーム

## このプロジェクトの目標

### 長期目標

より多い複雑なパターンのモグラ(ノーツ)を正確に叩くことにフォーカスした機能を実装する(記録管理、トレーニングモードなど)
BMSの主要なフォーマットを再生できる

### 短期目標

上からやる

#### ゲームエンジンをセットアップして、画面を表示できる

#### ダミーの譜面を表示できる

ここで使ったシーンがゲームプレイシーンになる

#### BMSファイルを読み込んで再生できる

#### キー入力を受け付ける

#### ゲームプレイができる

#### リザルトシーンを追加する

#### and more

## wgpu 2D 描画デモ

`app` クレートには、winit で作成したウィンドウに wgpu で 2 つの色付き矩形を描画する最小デモがあります。

```powershell
cargo run -p app
```

描画処理は次のように分けています。

- `crates/app/src/main.rs` はウィンドウイベント、GPU デバイス、Surface、レンダーパイプラインを管理します。ウィンドウサイズの変更時には Surface を再設定し、GPU Surface のロスト時にも再作成します。
- `VERTICES` はクリップ空間 ($x$, $y$ ともに $-1.0$ から $1.0$) の位置と RGB 色を持つ頂点列です。6 頂点で 1 つの矩形を構成するため、現在は 12 頂点で 2 矩形を描いています。
- `crates/app/src/shader.wgsl` は頂点座標をそのまま画面座標へ渡し、各頂点の色をフラグメントシェーダーで出力します。

譜面やノーツを表示する段階では、`VERTICES` を動的に生成・更新することで、同じパイプラインを 2D ゲーム画面の描画に拡張できます。
