# wakamore

音楽に合わせて遊べる高速モグラ叩きゲーム

## このプロジェクトの目標

### 長期目標

より多い複雑なパターンのモグラ(ノーツ)を正確に叩くことにフォーカスした機能を実装する(記録管理、トレーニングモードなど)
BMSの主要なフォーマットを再生できる

### 短期目標

上からやる

#### ゲームエンジンをセットアップして、画面を表示できる

#### ダミーの譜面を表示できる

ここで使ったシーンがゲームプレイシーンになる

#### BMSファイルを読み込んで再生できる

#### キー入力を受け付ける

#### ゲームプレイができる

#### リザルトシーンを追加する

#### and more

## wgpu 2D 描画デモ

`app` クレートには、ゲームウィンドウとデバッグウィンドウを別々に作成し、ゲーム画面には wgpu で 2 つの色付き矩形、デバッグ画面には egui で計測情報を描画するデモがあります。

```powershell
cargo run -p app
```

F12 でデバッグウィンドウを表示・非表示にできます。デバッグウィンドウを閉じた場合もゲームは終了せず、F12 で再表示できます。

処理は次のファイルに分けています。

- `crates/app/src/app.rs` は 2 つのウィンドウの生成、イベントの振り分け、更新・描画タイマーを管理します。
- `crates/app/src/game_renderer.rs` はゲームウィンドウ用の wgpu Surface と矩形描画を管理します。
- `crates/app/src/debug_renderer.rs` はデバッグウィンドウ用の wgpu Surface と egui 描画を管理します。
- `crates/app/src/performance.rs` はメインループ周波数とゲーム描画 FPS を計測します。
- `VERTICES` はクリップ空間 ($x$, $y$ ともに $-1.0$ から $1.0$) の位置と RGB 色を持つ頂点列です。6 頂点で 1 つの矩形を構成するため、現在は 12 頂点で 2 矩形を描いています。
- `crates/app/src/shader.wgsl` は頂点座標をそのまま画面座標へ渡し、各頂点の色をフラグメントシェーダーで出力します。

譜面やノーツを表示する段階では、`VERTICES` を動的に生成・更新することで、同じパイプラインを 2D ゲーム画面の描画に拡張できます。
